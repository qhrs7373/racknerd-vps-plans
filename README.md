## 线路名词一次讲清：同样是美国 VPS，为什么价格差几倍

| 线路类型 | 特点 | 适合 |
| --- | --- | --- |
| 国际线路（BGP/Global） | 走普通公网，价格最低，国内延迟高，晚高峰可能丢包 | 海外读者、练手、预算优先 |
| 9929 / CMIN2 | 联通 AS9929 加移动 CMIN2，国内三网都有优化，价格比 GIA 低 | 中文站主力的性价比档 |
| CN2 GIA | 电信精品网，双程 GIA，晚高峰相对稳，价格更高 | 国内读者为主、正式运营的站 |
| CN2 GT | 去程 GIA、回程 GT，晚高峰回程可能拥堵，延迟会波动 | 预算有限、又想比普通线好一点 |
| 双 ISP | IP 归属显示为美国本土 ISP，适合流媒体、TikTok 等原生 IP 场景 | 有原生 IP 需求的项目 |

CN2 GIA 和 CN2 GT 最容易混。GIA 是双程 GIA，去程回程都走精品路由；GT 是去程 GIA、回程 GT，晚高峰回程可能拥堵，延迟会波动。名字只差两个字母，晚高峰体验差不少。

## 买完 48 小时：先把网站跑起来，再谈优化

VPS 开通后，最容易卡住的是域名解析和面板。按下面顺序做，两个小时内能上线一个能访问的 WordPress；第一周再补缓存和安全。

1. **进 ctrl 面板重装系统**：选 Ubuntu 或 Debian，记下 IP 和 root 密码。ctrl 带 HTML5 VNC，系统起不来时不用额外工具就能进控制台。
2. **域名 A 记录指向 VPS IP**：在域名服务商处添加 A 记录，等待生效。解析没生效，后面装什么都访问不了。
3. **装可视化面板**：宝塔、1Panel 都可以，配好 LNMP 环境。不想用宝塔，也可以在 ctrl 的一键应用里装 CyberPanel 或 CloudPanel。
4. **部署 WordPress**：面板里一键部署，填数据库信息，绑定域名。整个过程通常十几分钟。
5. **开 HTTPS**：面板里申请 Let's Encrypt 免费证书，强制跳转 HTTPS。
6. **配缓存**：WordPress 装 WP Rocket 或 W3 Total Cache，再开服务器端缓存。1GB 内存的机器，缓存比升级配置更先见效。
7. **做第一次备份**：面板定时备份到对象存储或另一台机器，先手动跑一次，确认备份文件能下载。只存同机同盘，机器挂了备份也跟着没。
8. **基础安全**：改默认 SSH 端口，配好密钥后再禁用 root 密码登录，装 fail2ban，定期更新系统。

**前 48 小时只盯三件事：域名解析生效、面板能登录、第一次备份成功。** 这三件做完，网站就算上线了；缓存和安全可以边写内容边补。
